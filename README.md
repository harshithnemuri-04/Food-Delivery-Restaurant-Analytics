# Food Delivery & Restaurant Analytics
## Project Overview
This project focuses on analyzing food delivery and restaurant business data using Microsoft Power BI.
The dashboard provides insights into sales, total orders, average delivery time, customer ratings, restaurant performance, and payment methods.
## Tools & Technologies
- Microsoft Power BI
- Microsoft Excel
- Data Cleaning
- Data Visualization
- Data Analytics
## Key Performance Indicators (KPIs)
- Total Orders: 250
- Total Sales: 398.62K
- Average Delivery Time: 52.52
- Average Rating: 2.98
- Average Order Value: 1.59K
## Dashboard Features
1. Restaurant Type-wise Orders
2. City-wise Sales Analysis
3. Average Delivery Time by City
4. Repeat vs Non-repeat Customer Orders
5. Average Customer Rating by Restaurant Type
6. Payment Method Distribution
## Interactive Filters
- City: Bangalore, Delhi, Hyderabad, Mumbai
- Restaurant Type: Cafe, Casual Dining, Cloud Kitchen, Fast Food
- Payment Method: Card, Cash, UPI
## Business Analysis
- Compare sales performance across different cities.
- Analyze orders across restaurant categories.
- Understand average delivery time by city.
- Compare repeat and non-repeat customer orders.
- Evaluate customer ratings by restaurant type.
- Understand customer payment preferences.
## Project Files
- Dashboard: Power BI (.pbix) file
- Dataset: Excel (.xlsx) file
- Screenshots: Dashboard preview

To analyze food delivery business performance
and generate meaningful insights using interactive
Power BI dashboards.
